# Check-list — campagne 1

## La veille

- [ ] Lieu autorisé vérifié (B4UFLY + règlement du lieu) ; certificat TRUST
- [ ] Mise à jour du firmware et de DJI Fly faite **aujourd'hui** (pas sur place)
- [ ] 3 batteries, radiocommande et téléphone chargés ; hélices de rechange ; microSD vide
- [ ] Cible au sol (≥ 1 m de côté si possible), repère de décollage, mètre ruban ≥ 10 m
- [ ] Anémomètre ou application météo ; prévision : pas de pluie, vent < 5 m/s

## Sur place, avant le premier vol (à noter dans le carnet)

- [ ] Versions firmware / DJI Fly : ______
- [ ] Hauteur max **120 m** · distance max : ______ · hauteur de retour au départ : ______
- [ ] Mode débutant **désactivé** · mode **Normal** · évitement d'obstacles : ______
- [ ] Atterrissage de précision : activé / désactivé
- [ ] Repère de décollage posé, cible posée à côté, ligne de 200 m repérée (FE-05) : oui / non

## Avant chaque vol

- [ ] Vent mesuré < 5 m/s · personne dans la zone · hélices en bon état
- [ ] Drone centré sur le repère · point de départ enregistré · satellites ≥ 10
- [ ] Aucune alerte dans l'application
